# ironpathdistribution.com

Landing page for **Iron Path Distribution Group LLC** (Macon, GA).

Single static page (`index.html`), no dependencies, no build step.
Host it on any static host - the plan is Cloudflare Pages on the custom domain
`ironpathdistribution.com`.

## What's on the page

- Company name and location (Iron Path Distribution Group LLC, Macon, Georgia)
- What the business does: wholesale distribution, brand partnerships, marketplace retail
- Contact: justin@ironpathdistribution.com, scott@ironpathdistribution.com

## Editing

Everything is in `index.html` (markup + styles in one file). Edit, commit, and the
host redeploys automatically.
